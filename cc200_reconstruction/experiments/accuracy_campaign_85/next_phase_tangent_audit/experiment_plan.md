# Next-phase plan: strictly nested tangent-space evaluation (written and frozen before any corrected-model result exists)

Atlas: CC200 only. Data: the 676 authorized training subjects (313 ASD / 363 TC), 19,900 features + age + sex. The protected holdout, its IDs/labels/features/predictions and `RESTRICTED_id_membership.csv` are not accessed. Existing campaign results, reports, checkpoints and the frozen rule (`selection_rule.py`) are read-only; everything new is in this folder.
Starting point (verified in `fresh_seed_confirmation/report.md`): on seeds 3-5 the old tangent-space LR scored 66.81% (R1) / 67.46% (R0) against 66.47% / 67.16% for the 3-member soft vote and 65.29% / 66.03% for the reference LR.

## 1. Priority 1: what is being corrected
In the old pipeline (`campaign.py`, `provider("TS")`) the tangent reference (geometric mean) was fitted once on all outer-training covariances; the inner CV that chose C, and the inner CV that produced the threshold scores, then used features built with that reference, so each inner-validation subject had contributed to the reference used to transform it (label-free, but not strictly nested). The corrected procedure refits the reference separately inside every inner training split and applies it, without refitting, to that split's validation rows; the final outer-fold model refits the reference on the outer-training rows only and applies it to the outer-test rows. Everything else (demographic handling and scaling per fit, balanced L2 logistic regression, C grid {0.001, 0.01, 0.1, 1, 10}, inner 5-fold AUC with seed = outer seed, R1 threshold from inner 5-fold OOF scores with seed + 1000, outer 10-fold folds) is unchanged.
Validity checks before any result is trusted (details in `methodology.md`): (a) the new evaluator in "old mode" must reproduce the saved `P3_TS_LR` scores, best C and thresholds exactly for two outer folds; (b) synthetic tests that perturbing inner-validation or outer-test rows changes no fitted reference or any other row's output.

## 2. Hypotheses, comparisons and criteria (frozen now)
Reference arm: campaign P1_LR (balanced L2 logistic regression on Ledoit-Wolf correlation + Fisher-Z + age/sex), read from existing predictions for seeds 0-5 and run with the same engine for seeds 6-8. Primary reading R1 (threshold chosen from training-only inner scores); R0 (default thresholds) is secondary. Identical outer folds for all arms.
**H1 (Priority 2): the strictly nested tangent-space LR (TS-N) beats the reference LR.** Success on the confirmation seeds requires all of: (1) mean accuracy gain >= +0.5 pt; (2) positive accuracy gain in >= 2 of 3 seeds; (3) mean ROC-AUC change >= -0.005 (non-inferior AUC; a single-model change of representation is not expected to raise AUC the way an ensemble does).
**H3 (Priority 3, a single complementary-representation hypothesis): a 2-member soft vote of the reference LR (Fisher-Z features) and TS-N beats the reference LR.** Construction exactly as the saved ensemble code (Platt calibration of each member's training-only inner OOF scores, mean of calibrated probabilities, R1 threshold from the ensemble's own inner scores). Success: (1) mean accuracy gain vs reference >= +0.5 pt; (2) positive in >= 2 of 3 seeds; (3) mean AUC gain >= +0.01. Also reported against TS-N alone (informational, not part of the decision).
Not tested, with reasons: regularized partial correlation (already 5 points below the reference with AUC 0.667 in the campaign; no new justification for a further variant); in-fold feature selection (SelectKBest, PCA and L1 selection already tried, none helped); combining all representations (explicitly excluded).

## 3. Seeds and stages (the schedule is fixed; the only conditional is stated)
- **Stage A, exploratory: seeds 0-2.** Compare TS-N with the reference LR and with the old (non-nested) TS LR from existing results (the old model's seed 0-2 results were already seen, and the same seeds were used for selection, so this stage is exploratory and decides nothing). It also measures the effect of the correction (TS-N minus old TS).
- **Stage B, formal confirmation: seeds 6, 7, 8.** These partitions were never used by any earlier model, so they are fresh for this hypothesis. **Run only if** Stage A shows a mean TS-N accuracy gain over the reference of at least +0.25 pt (R1); otherwise the experiment stops with a documented negative result.
- **Stage C, supplementary: seeds 3-5**, run only if Stage B is run. The task brief named seeds 3-5 as fresh, but the old tangent model's accuracy on exactly those seeds is what motivated this work, so they are not independent for this hypothesis; they are reported as a supplementary comparison and cannot carry the confirmation.
The success criteria in section 2 are evaluated on Stage B only. They are not changed after results are seen.

## 4. Outputs and safeguards
`experiment_plan.md`, `methodology.md`, `results.csv`, `predictions.csv`, `final_report.md`, source code (`tangent_nested.py`), logs, checkpoints, `hashes_before.json` / `hashes_after.json` (inputs, code, rule, reports, covariance cache, existing checkpoints; compared after every stage). All metrics: accuracy, balanced accuracy, sensitivity, specificity, precision, F1, ROC-AUC, confusion matrices, per-seed and per-fold values, paired fold differences, mean and SD over seeds, runtime and failures. No result is selected by seed or fold.

## 5. Compute (measured)
One tangent reference fit takes 31-39 s (22 iterations); the strictly nested evaluation needs 11 fits per outer fold (5 for C selection, 5 for threshold scores, 1 final), about 400 s of CPU per fold. Outer folds run in parallel worker processes (single-threaded numerics). Estimated 15-30 min per 3-seed stage; whole plan under about 2 hours.
